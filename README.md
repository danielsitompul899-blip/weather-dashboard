# Weather Dashboard

Weather Dashboard adalah website yang menampilkan kondisi cuaca saat ini
dan prakiraan lima hari berdasarkan kota yang dicari pengguna.

## Live Demo

https://danielsitompul899-blip.github.io/weather-dashboard/

## Fitur

- Pencarian kota.
- Suhu saat ini.
- Kelembapan.
- Kecepatan angin.
- Curah hujan.
- Prakiraan lima hari.
- Deteksi lokasi pengguna.
- Dark mode.
- Responsive design.
- Loading dan error state.

## Teknologi

- HTML5.
- CSS3.
- JavaScript.
- Fetch API.
- Geolocation API.
- Open-Meteo API.
- GitHub Pages.
